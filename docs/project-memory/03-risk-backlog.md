# 03-risk-backlog

## P0
- 鉴权链路变更风险：`JWT + Casbin + 动态菜单`三者耦合，变更需联动验证。
- 自动代码与运行时代码并存：模板/生成逻辑误改可能影响核心业务目录。

## P1
- 全局状态依赖风险：`global.*` 共享对象增多，重载与并发场景需重点回归。
- 插件边界风险：插件与主系统 API 演进不一致时可能引发兼容问题。
- 测试覆盖风险：测试文件数量偏少，核心链路需补充集成校验。

## P2
- 文档老化风险：项目迭代后若不刷新索引，定位精度会逐步下降。
- 前端页面规模膨胀风险：系统工具域页面体量较大，建议按功能拆分。

- 逻辑段总数：4769
